# Kinwoven project instructions

These instructions apply to the entire project.

- Optimize for grandparents completing a meaningful action with little help. One main action per screen, plain language, large controls and predictable back navigation.
- Runtime AI must use Firebase AI Logic Hybrid Inference SDK. Prove on-device and cloud execution separately and report actual source. Fixtures remain labeled test fixtures.
- Local-only means no application upload, telemetry of memory content or cloud inference. Family sync is a separate explicit action. App Check protects cloud access but does not replace family authorization rules.
- Draft only from provided facts. Photo descriptions are tentative observations. Do not infer identities, relationships, dates, feelings or events from appearance. Uncertainty becomes a question for the family.
- AI output is untrusted data. Parse and validate it. Render as text, never raw HTML. Permission and publication decisions are deterministic.
- Approvals bind to immutable story and media revisions. A later edit requires new approval. Enforce membership on every shared resource operation.
- Use the smallest coherent implementation. Keep existing work safe. Record actual checks and blockers in docs/PROGRESS.md and SESSION_CONTINUATION.md.
- No decorative footer, attribution bar, signature, badges or powered-by strip. Keep license notices, source acknowledgments and mandatory disclosures in body/reference files. The same ban covers commit footers, README closing lines and video end cards: no "built with" or AI-tool attribution.
- Keep secrets, family media, private transcripts and signed resource links out of Git, screenshots and session memory. Documentation uses placeholders.
