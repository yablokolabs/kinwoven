# Synthetic demo photographs

These three images are AI-generated test material. They are not family photographs, do not depict
real people, and must not be presented as evidence of a memory.

- `kitchen-table.jpg` — a kitchen table with a radio, teapot and open notebook. Used as the demo
  video's uploaded photo and labelled `SYNTHETIC` on screen.
- `garden-bench.jpg` — garden bench, hats and planting.
- `photo-album.jpg` — open book on a wooden table.

Generated with Pollinations.ai's image endpoint in November 2026. The free endpoint adds a small
service mark; the mark was cropped from the bottom edge of each file. Prompts asked for objects
only, with no people and no readable text, so the fixtures cannot imply identities, relationships
or dates.

For the video, the demo story text is built from the same plain notes typed into the app. It is not
model output and the app labels it as a plain draft.
