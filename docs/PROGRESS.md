Bugs found by the proof and fixed: the SDK returned lowercase `on_device` while the app compared uppercase `ON_DEVICE`, so a valid local result was rejected; `normalizeInferenceSource` now normalizes both cases and `assertSourceAllowed` rejects unknown sources. The v1 draft also expanded a supported `Sunday` into unsupported `Sunday morning` and added generic praise. Prompt v2 forbids time-of-day/occasion expansion, filler, greetings and questions in the story, and passes the system instruction to the cloud path too. A deterministic review now flags a short list of unsupported time, people, feeling and filler words for correction. The v2 capture has no `morning`; it retains `Sunday` and flags the remaining `day`, `family`, `remember` and `photo` words. Checks after these changes: `npm run typecheck` exit 0, 34/34 tests, `npm run build` exit 0.
